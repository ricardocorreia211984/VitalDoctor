## 💬 PARTE 5: OBJEÇÕES E RESPOSTAS

### **"Como funciona se Supabase/Vercel caem?"**

```
Resposta:

"Ótima pergunta! Supabase e Vercel são líderes
no mercado com 99%+ uptime. Mas tens razão:
qualquer serviço pode ter problemas.

Por isso:
1. Fazemos backup diário (você consegue restaurar)
2. Se cair, migramos para outra plataforma em <1h
3. Documentação completa de recuperação
4. Você é dono dos dados, pode sair quando quer

Além disso:
- Usamos serviços grátis (melhor relação preço/uptime)
- Se quiseres 100% garantido: compra licença permanente
- Você instala no vosso servidor, responsabilidade sua

Faz sentido?"
```

---

### **"Preciso de suporte 24/7?"**

```
Resposta:

"Depende do teu modelo:

SaaS (€30-50/mês):
├─ Suporte por email (24-48h)
└─ Não há suporte 24/7 neste preço

Profissional (€50/mês):
├─ Suporte prioritário (24-48h)
└─ Suporte VIP se upgrade

Licença (€2000-5000):
├─ Instalação e setup incluído
├─ Suporte 1-2 anos
└─ Depois: suporte pago (opcional)

Se precisas 24/7 realmente:
├─ Podemos arranjar (contra custo)
├─ €200-300/mês de suporte dedicado
└─ Ou: escalação para programador

Vale a pena? Geralmente não para solo.
Melhor: grupo de terapeutas partilha um técnico."
```

---

### **"Posso piratear o código?"**

```
Resposta (firme mas profissional):

"Tecnicamente consegues. Mas não aconselhamos:

Risco Legal:
├─ Código é propriedade nossa (copyright)
├─ Violação é crime (varia por país)
├─ Processos legais (€2000-10000 custos)
└─ Reputação danificada

Risco Prático:
├─ Precisas sysadmin (não é grátis)
├─ Bugs? Teu problema (sem suporte)
├─ Atualizações? Manutenção tua
├─ Segurança? Responsabilidade tua
└─ Roubo de dados? Teu risco

Solução Honesta:
├─ Licença €2000-5000 (cumpre comigo)
├─ Você é dono do software
├─ Sem culpa
└─ Recomendado para quem quer independência total

Qual faz sentido para ti?"
```

```
Resposta:

"Depende do modelo:

├─ 5 clientes a €50/mês = €250/mês
├─ 10 clientes = €500/mês
├─ 20 clientes = €1000/mês
├─ Tempo: 6-12 meses para ROI
└─ Depois: lucro crescente

Licença (One-time):
├─ 1 venda a €2000 = €2000 lucro

├─ Tempo: 1-3 vendas (1-3 meses)

├─ Goal: €500-1000/mês em 6 meses
└─ Depois: scale or scale (mais como lançador)

Na prática:

- Consegues 5-10 primeiros clientes rápido
```
